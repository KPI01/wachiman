# AGENTS.md

## Project Overview

`control-accesos` is Fruveco's role-based visitor access-control application
with a Spanish-language UI.

Technology stack:

- React Router 8 in framework mode with SSR
- Vite 8 and React 19
- Drizzle ORM, better-sqlite3, and SQLite
- Tailwind CSS 4 and shadcn/ui
- pnpm 10

## Mandatory Rules

### User Communication

- Always respond to the user in Spanish.
- Keep all new UI copy in Spanish.
- Never modify files inside `node_modules/`.

### Package Management and Validation

- Use **pnpm 10** exclusively. Do not use npm or Yarn.
- Run `pnpm typecheck` after code changes. This is the required validation command.
- Run `pnpm build` before deploying a new image.
- Do not rely on `pnpm lint`; it is currently broken because the project has no `eslint.config.js`.
- Do not add alternate edge or worker deployment support.

### Architecture

- Routing is declarative in `app/routes.ts`; route types are generated by `pnpm typecheck`.
- Keep server-only code in `*.server.ts` modules and never import it from client-side code.
- Database entities in `app/lib/database/*.server.ts` use the `db` proxy from `db/server.ts`.
- `db/client.ts` initializes Drizzle over local SQLite. `DATABASE_URL` uses the `file:` form.
- Keep validation schemas in `app/lib/schemas` and business logic in `app/lib/services` when it is shared or non-trivial.

## Development Commands

- `pnpm dev` starts the local development server.
- `pnpm typecheck` runs React Router type generation and TypeScript.
- `pnpm build` creates the production bundle in `dist/`.
- `pnpm start` serves the production bundle on port 3000.
- `pnpm db:migrate`, `pnpm db:setup`, `pnpm db:seed`, and `pnpm db:reset` manage SQLite.
- `pnpm env:set-encryption-key` and `pnpm env:set-session-secret` write secrets to an env file.

## Authentication and Security

- Protected routes use `isAuthenticated` or `validateUserRole` from `app/lib/auth.server.ts`.
- The session cookie is `control-accesos-session` and has an eight-hour lifetime.
- Production runs behind HTTPS, so `SESSION_COOKIE_SECURE` must remain `true`.
- `crypt.server.ts` uses AES-256-GCM. `ENCRYPTION_KEY` must be a base64-encoded 32-byte key.
- Keep `.env.production` out of Git and never expose its secrets.

## Deployment

- Production uses `podman compose` with `docker-compose.yml`.
- The application binds only to `127.0.0.1:3000` and persists data in `control_accesos_sqlite_data` and `control_accesos_uploads_data`.
- Host Caddy publishes `https://control-accesos.fruveco.com` and `https://192.168.100.172:8444` using `deploy/host-caddy/control-accesos.caddy`.
- Devices must trust Caddy's internal root CA before accessing either HTTPS endpoint.

## UI Conventions

- shadcn/ui primitives live in `app/components/ui`.
- Feature components live in `app/components/models`.
- Use `cn()` from `app/lib/utils.ts` to compose classes.
- Continue using the Spanish `date-fns` locale for date formatting.
